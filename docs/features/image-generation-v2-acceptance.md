# 局部重绘、会话图片引用与独立 Provider 验收

日期：2026-10-06。基于既有 `feat/qwen-image-workbench`，Linux x64、Node 24.14.0、pnpm 10.33.2。

## 实现范围

- 涂抹、橡皮擦、撤销、清空、缩放、键盘与触屏选区；原尺寸 PNG 输出，每次重绘产生新版本。
- 参考图选择器展示当前会话所有成功生成的图片，按选择顺序加入，复用原始产物 ID；目标计入五张限制。
- 在画布中创建或修改独立生图 Provider 的名称、地址、密钥。纯生图 Provider 无需聊天模型；缺少配置时明确报错，不读取会话模型的 Provider。旧设置需明确选择一次。

## 真实 Qwen 请求

复用之前生成的 512×512 红茶壶照片，选取壶身 6,180 个像素区域，要求绘制白色五角星。真实 Qwen 请求完成并返回 PNG：选区内 6,180 个像素发生变化，选区外 255,964 个 RGBA 像素逐一检查完全相同。实际查看确认出现白色五角星；选区内部分釉色、反光仍有变化，硬边矩形选区可以看出局部接缝。

当前代理拒绝原生 mask 字段，因此本实现采用选区视觉引导和 Host 合成，不能称为原生扩散蒙版重绘。软件保证选区外像素保持原样；选区内的画面质量取决于模型与选区，必须查看结果。

## 限制

CLI 全量 Lint 仍被原有 `telemetry` 文件超过 400 行的错误阻挡；这些文件不在本次改动范围。Windows/macOS 实机、真实另一台手机及远程 Host 未验证；手机尺寸与触屏事件在 Linux 浏览器/Electron 自动化中验证。此前完整真实 GLM/Qwen 多参考图矩阵与 TUI 记录见 [首版验收报告](image-generation-acceptance.md)，本次没有重复该矩阵和 310 秒等待。
