# 图像画布验收记录

验收日期：2026-10-03 至 2026-10-04。基线：官方 ZCode 3.14.3，`29628c9`。环境：Linux x64、Node 24.14.0、pnpm 10.33.2、Electron 41.0.3。

## 验证方式

确定性测试使用本机 HTTP 模拟服务；真实测试使用隔离的 LocalLLMProxy 路由实例、独立测试密钥和数据目录，连接实际 GLM-5.3 与 Qwen-Image-2.1。真实请求串行执行，只使用已确认稳定的 512/1024 范围，没有测试已知 OOM 组合。原代理源文件未修改。

截图和模型生成的文件均实际打开检查，同时读取任务记录、网络记录、尺寸、MIME、Alpha 与文件哈希。CLI/TUI 的终端画面来自真实 PTY 字节回放。验收原始文件位于本机 `.evidence/`，包含私有路径及运行信息，因此不提交；仓库保留可重复运行的脚本与本报告。

| 输出 / 参考数    | 实际结果                                             |

| 768×512 JPEG / 1 | 通过：JPEG解码、横构图与改色正确。                   |
| 512×768 PNG / 1  | 通过：竖构图、颜色与原场景正确。                     |

多参考图的构图偏差是实际观察到的模型效果限制。Skill建议局部改动优先仅用目标图，额外参考图需明确用途；界面没有隐藏这些结果或自动重试。

上游JPEG请求曾返回500，用户确认原因为`cannot write mode RGBA as JPEG`。适配器改为单次请求PNG，在Host按指定质量合成白底并编码JPEG；无第二次生图请求，结果保留编码元数据。
