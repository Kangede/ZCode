# 图像编辑器界面改版验收

日期：2026-10-06。基于 `932f577`，沿用独立 Provider、会话图片引用和局部重绘执行层。

## 界面调整

- 以居中的大画布为主，底部固定提示词、参考图入口、参数摘要和生成/取消按钮。
- 服务配置、参数、参考图库收进弹出面板；保留版本比较、下载、项目导出和复用参数。
- 版本历史使用缩略图；涂抹使用单条悬浮工具栏，选区统一半透明显示。
- 当前画布上的编辑目标不再重复占用输入区缩略图位置，其它参考图保留实际提交编号。
- 参数面板关闭后保留涂抹；退出选区模式保留提示词。Ctrl/⌘+Enter 提交，生成中不会重复提交。
- 修复切换为空白画布或其它版本时旧下载 URL 的短暂残留，确保下载属于当前版本。

交互参考 [官方图像查看与编辑流程](https://learn.chatgpt.com/docs/image-generation)，视觉样式结合 ZCode 的主题、字体和组件规范实现，不宣称逐像素复制某个 Codex 版本。
